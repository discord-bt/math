# Contribuindo

Este projeto distribui somente cores de perfil e painéis informativos. Ao propor uma mudança, descreva o problema, o comportamento esperado e como reproduzi-lo.

Use uma branch separada e mantenha as alterações pequenas. Preserve as verificações de permissão, os identificadores dos botões persistentes e a compatibilidade das configurações já salvas. Não inclua tokens, bancos de dados, registros de membros ou configurações de um servidor real.

Execute `python -m unittest discover -s tests` e teste as interações em um servidor de desenvolvimento antes de publicar. Inclua no pedido de revisão quais passos foram verificados no Discord. As verificações locais não substituem esse teste.

Ao enviar uma contribuição, você concorda em disponibilizá-la sob a licença BSD-3-Clause deste projeto. O projeto não é afiliado ao Discord nem ao projeto discord-math/bot. Não há garantia de suporte individual.
